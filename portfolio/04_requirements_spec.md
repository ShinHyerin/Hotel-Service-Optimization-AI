# 📋 04. 요구사항 정의서 (Requirements Specification)

본 통합 솔루션이 제공하는 3가지 핵심 모듈(ML/Flask, YOLOv11, SLM 챗봇)의 기능적 요구사항과 품질 및 인프라적 제약조건을 정의한 명세서입니다.

---

## 1️⃣ [ML/Flask] 호텔 예약 취소 확률 예측 시스템

| 요구사항 ID | 분류 | 요구사항 명칭 | 상세 명세 (기능 및 제약조건) |
| :---: | :---: | :--- | :--- |
| **REQ-ML-01** | 기능 | 실시간 취소율 예측 기능 | 사용자가 8가지 핵심 변수(`lead_time`, `country` 등)를 변경할 때마다 AI 모델이 `is_canceled` 확률을 실시간으로 계산하여 반환해야 함. |
| **REQ-ML-02** | 기능 | 비동기 대시보드 연동 | 화면 전체의 새로고침 없이 **JavaScript Fetch API**를 통해 실시간 예측 데이터가 그래프(`Chart.js`)에 즉각 반영되어야 함. |
| **REQ-ML-03** | 기능 | 예약 취소 및 가중치 반영 | 예약 내역 검색 후 **[예약 취소]** 수행 시, 해당 고객의 과거 취소 이력(`previous_cancellations`)을 즉시 `+1` 누적하여 차후 예측 및 DB 전체 통계 지표에 반영해야 함. |
| **REQ-ML-04** | 비기능 | 데이터베이스 호환성 | Oracle 11g Express Edition 환경과의 안정적인 호환성을 위해 `oracledb` 라이브러리의 **Thick Mode 클라이언트**를 활성화하여 세션을 유지해야 함. |

## 2️⃣ [YOLOv11] 공유 공간 이용 실태 분석 시스템

| 요구사항 ID | 분류 | 요구사항 명칭 | 상세 명세 (기능 및 제약조건) |
| :---: | :---: | :--- | :--- |
| **REQ-CV-01** | 기능 | 멀티 클래스 객체 탐지 | 입력되는 실시간 영상 프레임에서 사람(`Person`), 노트북(`Laptop`), 가방(`Bag`) 객체를 독립된 클래스로 동시에 식별해야 함. |
| **REQ-CV-02** | 기능 | 관계 인지형 노쇼 판별 로직 | 단순히 사람 수만 세는 것이 아니라, 객체 간의 조합을 파악하여 **노쇼**(사람 0/물건 0), **자리비움**(사람 0/물건 ⭕), **이용률 저조** 상태를 조건부 비즈니스 로직으로 인지해야 함. |
| **REQ-CV-03** | 기능 | 확장형 REST API 통신 | CCTV 스트리밍 스크립트(클라이언트)와 YOLOv11 추론 엔진(서버) 간의 데이터 송수신은 JSON 포맷의 **RESTful API**를 통해 처리하며, 향후 여러 공간(`Room ID`)으로 확장 가능해야 함. |
| **REQ-CV-04** | 비기능 | 실시간성 (Latency) | 이미지 분석 요청(CCTV 단)부터 추론 결과 응답 및 프론트엔드 UI 업데이트까지 걸리는 총 지연 시간은 **1초 이내($Latency < 1s$)**여야 함. |

## 3️⃣ [SLM] 가상 호텔 사내 규정 안내 챗봇

| 요구사항 ID | 분류 | 요구사항 명칭 | 상세 명세 (기능 및 제약조건) |
| :---: | :---: | :--- | :--- |
| **REQ-NLP-01** | 기능 | 구어체 및 의도 추출 (NER) | 문법에 완벽하지 않은 사용자의 정제되지 않은 일상 대화체나 구어체 질문 속에서 핵심 엔티티(장소, 물품 등)와 질의 의도를 정확히 식별해야 함. |
| **REQ-NLP-02** | 기능 | 매뉴얼 기반 팩트 체킹 (QnA) | AI가 다른 정보를 임의로 가져오지 못하도록, 반드시 시스템에 탑재된 **호텔 사내 운영 규정 문서 데이터 범위 내에서만** 정답 후보군을 도출해야 함. |
| **REQ-NLP-03** | 기능 | 환각(Hallucination) 제어 | 사내 매뉴얼 범위를 벗어난 도메인 외 질의에 대해서는 허위 답변을 지어내지 않고, *"해당 정보는 매뉴얼에 등록되어 있지 않습니다."* 등의 지정된 고정 방어형 답변을 출력하도록 예외 처리를 해야 함. |
| **REQ-NLP-04** | 비기능 | 추론 속도 및 자원 효율성 | 자연어 쿼리 입력 후 최종 답변 출력까지 걸리는 시간은 **최대 3초 이내**여야 하며, 고가의 다중 GPU 인프라 없이 단일 GPU 혹은 로컬(On-Premise) 환경에서 구동 가능하여 내부 보안을 유지해야 함. |
