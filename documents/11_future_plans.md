# 📋 11. 향후 개발 계획 (Future Development Plans)

본 문서는 호텔 서비스 최적화 AI 플랫폼의 1차 모듈(Flask ML) 구현 이후, 시스템 고도화 및 후속 Core 모듈(YOLOv11 비전, SLM 챗봇)의 단계별 통합 로드맵을 정의합니다.

---

## 1. Flask 기반 호텔 예약 취소율 예측 시스템 고도화
* **이벤트성 시즈널리티(Seasonality) 특성 반영**
  * 크리스마스, 연말연시, 명절 등 특정 이벤트성 날짜에 임박하여 발생하는 예약 데이터의 경우, 일반 기간 대비 취소율이 급격히 감소하는 가치 있는 도메인 패턴 확인. 
  * 파생 변수(Feature Engineering) 생성을 통해 가중치 부여 및 모델 추론 정밀도 향상 추진.
* **실시간 피드백 알고리즘 추가**
  * 사용자가 예약 날짜를 선택할 때, 해당 기간의 시즈널리티 가중치를 백엔드에서 동적으로 계산하는 아키텍처 설계.
  * `"이벤트성 공휴일에 근접한 예약으로 취소 확률이 낮게 산출됩니다"`와 같은 정성적 가이드 메시지를 브라우저에 비동기(Fetch API)로 실시간 제공하는 UI/UX 기능 구현 예정.

---

## 2. YOLOv11 기반 실시간 공간 모니터링 시스템 구축
* **모델 학습 및 최적화**
  * Roboflow 플랫폼을 활용한 맞춤형 데이터셋 구축 및 이미지 라벨링 프로세스 완료.
  * WSL2 Ubuntu 인프라 환경에서 PyTorch 프레임워크 기반의 YOLOv11 알고리즘 본격 학습 돌입 및 객체 탐지(Object Detection) 모델 가중치 최적화.
* **RESTful API 연동 파이프라인 확장**
  * 학습이 완료된 비전 가중치 파일(`.pt`)을 독립적인 실시간 객체 추론 모듈로 패키징 처리.
  * 기존 Flask 백엔드 서버에 RESTful API 아키텍처 구조로 결합하여, 공간 분석 매핑 데이터를 실시간으로 서빙 및 송수신하는 파이프라인 데이터 흐름 구현 예정.

---

## 3. Hugging Face SLM 기반 사내 문서 QnA 모듈 개발
* **도메인 특화 지식베이스(Knowledge Base) 참조**
  * 프로젝트 기획 및 설계 단계에서 사전 작성된 요구사항 분석서, 시스템 설계 사양서, 호텔 도메인 운영 매뉴얼 가이드 문서를 전처리하여 인풋 데이터 원천으로 지정.
* **문서 기반 Context 추론 구현**
  * Hugging Face 프레임워크의 Transformers 라이브러리를 활용하여 소형 거대 언어 모델(SLM)을 로컬 서버 환경에 독립 빌드.
  * 수집된 규정 문서를 RAG(검색 증강 생성, Retrieval-Augmented Generation) 파이프라인 형태로 임베딩 및 참조하여, 실시간 질의응답 및 예외 대응이 가능한 지능형 챗봇 모듈로 확장 개발 예정.
