## 📊 1. [ML/Flask] 호텔 예약 취소 예측 모듈

### 🛑 Issue 01: 도메인 가설과 실제 데이터 간의 모순으로 인한 모델 노이즈 발생
* **분류:** 데이터 전처리 (Feature Engineering) & 모델 최적화

#### 1. 현상 (Situation & Task)
* 호텔 예약 취소 여부(`is_canceled`)를 예측하기 위해 초기 피처 엔지니어링 단계에서 보증금 정책 변수(`deposit_type`)를 모델 학습 피처로 포함시킴.
* 일반적인 도메인 상식선에서는 **"보증금이 없는 예약(No Deposit)일수록 취소 부담이 적어 취소율이 높고, 보증금이 걸려있으면 취소율이 낮을 것"**이라는 가설을 수립함.

#### 2. 원인 분석 (Action)
* 수립한 가설을 검증하기 위해 원본 데이터셋 내 `deposit_type`에 따른 실제 취소율 통계를 교차 분석(Cross-Tabulation)하여 시각화 및 검증을 수행함.
* 분석 결과, 가설과 정반대로 **보증금이 없음에도 불구하고 예약을 취소하지 않고 정상 투숙한 고객의 데이터 비율이 압도적으로 높음**을 발견함. 
* 도메인 상식과 실제 수집된 Kaggle 데이터 간의 극심한 불일치(모순)가 존재함을 확인하였으며, 이 변수를 그대로 학습시킬 경우 모델이 특정 편향(Bias)을 학습하여 과적합(Overfitting)을 유발하고 예측 정확도를 떨어뜨리는 노이즈로 작용할 것이라 판단함.

#### 3. 해결 방안 (Result)
* 모델의 강건성(Robustness)과 범용적인 정확도를 확보하기 위해, 변수 중요도(Feature Importance) 분석을 거쳐 해당 `deposit_type` 피처를 학습 데이터셋에서 과감히 제거(`Drop`) 조치함.
* **성과:** 불필요한 도메인 노이즈 변수를 제거함으로써 모델의 복잡도를 낮추어 추론 속도를 향상시켰으며, 검증 데이터셋(Validation Set) 기준 분류 모델의 최종 정확도(Accuracy) 및 예측 안정성을 향상시킴.
