## 📝 주차별 핵심 마일스톤 (Milestone)

### 📌 1주차 ~ 2주차 초입: 파이프라인 기반 다지기
* Kaggle 원본 데이터를 정제하여 핵심 피처(`adr` 포함 8개 변수) 중심의 타깃 테이블 구조 확립 및 오라클 서버 적재 성공.
* 파이썬 스크립트를 통한 데이터 입출력 스트림 검증 및 분류 모델 초안 설계 완료.

### 📌 2주차 중반: UI/UX 레이아웃 및 서빙 가이드 구축
* 비동기 데이터 변화를 실시간으로 받아줄 사용자 중심의 모던 대시보드 화면 설계.
* 차트 영역과 예측값 입력 폼 배치를 설계하여 화면 새로고침 없는 사용자 경험(UX) 확보.

### 📌 3주차: 서버 연동, 비동기 API 완성 및 최종 최적화
* Flask 서버 인프라에 `joblib` 모델 추론 엔진을 얹고 프론트엔드 Fetch API와 유기적으로 데이터를 주고받는 엔드포인트 전면 구축.
* 사용자가 [예약 취소]를 처리했을 때 DB의 `previous_cancellations`가 즉각 반영되는 피드백 루프 파이프라인 검증 및 예외 처리 완료 후 최종 제출.
